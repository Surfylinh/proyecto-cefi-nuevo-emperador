# 🏫 Proyecto Interdisciplinario: CEFI Nuevo Emperador
> **"Ciencia, Historia y Tecnología al Servicio de la Comunidad Educativa"**

Plataforma web híbrida desarrollada para el **CEFI Nuevo Emperador** por los estudiantes de **11°A Informática (Año Lectivo 2026)**. Este proyecto integra las materias de **Programación, Multimedia, Química, Física e Historia**, combinando contenido educativo estático, animaciones dinámicas y un backend de procesamiento de ecuaciones científicas.

---

## 🚀 Tecnologías Utilizadas

- **Front-End:** HTML5, CSS3 (Flexbox & CSS Grid), JavaScript (ES6+ & `IntersectionObserver`)
- **Back-End:** Python 3, Flask (Jinja2 Templates)
- **Multimedia / 3D:** Three.js / WebGL (`.glb` models)

---

## 📁 Estructura del Repositorio

```text
Proyecto multidisciplinario/

## 🛠️ Cómo Ejecutar el Proyecto Localmente
1. Páginas Estáticas:

Puedes abrir cualquier archivo .html (index.html, History.html, etc.) directamente en tu navegador preferido.
2. Módulo de Calculadoras (Flask):

Para ejecutar el servidor Back-End en Python:
# 1. Clonar el repositorio
git clone [https://github.com/TU-USUARIO/TU-REPOSITORIO.git](https://github.com/TU-USUARIO/TU-REPOSITORIO.git)

# 2. Entrar a la carpeta
cd flask

# 3. Instalar Flask (si no lo tienes)
pip install flask

# 4. Ejecutar el servidor
python app.py
Abre tu navegador en http://127.0.0.1:5000 para interactuar con las calculadoras científicas.
